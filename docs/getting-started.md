# Getting started

peQL lets you attach data quality rules and access policies to a dataset, then query it with SQL. The engine applies those rules for the person, agent or service making the query.

Start with Concepts if these ideas are new to you, or follow the Quickstart to see them in action. You only need basic SQL for the example.
